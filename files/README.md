Сюда кладутся файлы, которые проносят в контур. Каталог в git пустой: пакет, контрольные суммы и ключ в репозиторий не коммитятся.

Нужны четыре файла:

- `openbao_2.6.2_linux_amd64.deb` или `.rpm` под архитектуру сервера
- `checksums.txt` из того же релиза
- `tls.crt` — сертификат внутреннего УЦ на имя из `openbao_api_addr`
- `tls.key` — закрытый ключ этого сертификата

Имена пакетов: `openbao_<версия>_linux_<arch>.deb` и такой же `.rpm`. Для x86_64 в имени файла стоит `amd64`, для aarch64 — `arm64`. Пакет `openbao-hsm` не используется.
