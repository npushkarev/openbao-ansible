Пакеты OpenBao 2.6.2 для x86_64 и `checksums.txt` из релиза. `install.sh` сверяет пакет с `checksums.txt` перед установкой. Сверка ловит повреждение при переносе, но не подмену: оба файла едут вместе.

`openbao-unseal` снимает печать. `install.sh` ставит его как `/usr/local/sbin/openbao-unseal`.

`tls.crt` и `tls.key` необязательны. Если их нет, `install.sh` выпустит самоподписанный сертификат на адрес машины. Свой сертификат кладите сюда до запуска, нужны оба файла. В репозиторий они не попадают.
